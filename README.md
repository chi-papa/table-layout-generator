# table-layout-generator
HTMLテーブルを視覚的に作成・編集できる軽量ジェネレーター。CSS分離・インライン・RMS SP/PC向けHTMLに対応。ブラウザだけで動作するローカル完結型ツール。

## セキュリティ・プライバシー

- HTML・CSS・JavaScriptのみで構成された単一ファイルのツールです。
- 外部ライブラリや外部APIに依存していません。
- ダウンロードしたHTMLファイルをブラウザで開くことで、ローカル環境で利用できます。
- ツールの動作に外部サーバーへのデータ送信は必要ありません。

※GitHub Pagesなどで利用する場合、HTMLファイルの配信には外部通信が発生します。ローカル利用時とは通信環境が異なります。
